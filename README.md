# AWS DevOps CI/CD Web Application

A static web application deployed through a complete CI/CD pipeline.

## Technologies

- HTML, CSS, JavaScript
- Git and GitHub
- Jenkins
- Docker
- Docker Hub
- Kubernetes (K3s)
- AWS EC2 Ubuntu

## Pipeline

VS Code → GitHub → Webhook → Jenkins → Docker Hub → Kubernetes

## Application

The application is exposed using a Kubernetes NodePort Service.
